관리자용 차량 30대 · 주요 운전자 사전 등록 및 초기 세팅 가이드

본 문서는 시스템 오픈 전 관리자가 ① 법인차량 30대 초기 데이터와 ② 주요 운전자(임직원) 사전 명단을 수합하여 관리자 콘솔(보안 PIN)에 일괄 입력하고 운영하는 전 과정을 항목별 인포그래픽으로 정리한 공식 지침서입니다.

ITEM 01 관리자 사전 준비 및 초기 세팅 4단계 마스터 로드맵

전체 소요시간: 약 30분 (최초 1회)

차량 내 블랙박스나 OBD 단말기를 설치하지 않는 대신, 관리자가 최초 1회 차량 기본 정보(블루투스 MAC·계기판 거리)와 주요 운전자 명단을 CSV로 등록해 두면 이후 모든 배차·추적·세무일지가 100% 자동화됩니다.

[인포그래픽 01] 관리자 초기 데이터 수합(차량 30대 + 주요 운전자) → CSV 일괄 업로드 → 현장 가동 4단계 파이프라인

ITEM 02 법인차량 30대 초기 정보 조사 및 등록 가이드 (7대 필수 항목)

차량 1대당 최초 1회 조사

관리자는 차량에 별도 기기를 장착할 필요 없이, 아래 인포그래픽에 표시된 차량 7대 고유 정보를 조사하여 엑셀(CSV) 시트에 기록하거나 관리자 화면에서 직접 입력합니다.

[인포그래픽 02] 차량 1대당 관리자가 초기에 수집·입력하는 7대 핵심 데이터 위치도
CSV 컬럼명 항목명 (국문) 입력 예시 관리자 수집 방법 및 활용 목적
fleetNumber 호차 번호 1 ~ 30 사내 관리 번호 (#01호차 ~ #30호차). 기존 호차 번호와 동일하면 업로드 시 자동 덮어쓰기(Update)됩니다.
plateNumber 차량 번호판 AL 41A-2237 미국 앨라배마주 Lee County 법인 번호판. IRS 세무 운행일지(Sec. 274d)의 차량 식별자로 사용됩니다.
modelName 차종 명칭 Hyundai Santa Fe 임직원이 배차 신청 시 차종(SUV/세단/전기차)을 식별하기 위한 모델명입니다.
btMacAddress 순정 블루투스 MAC A4:C1:38:90:01:AA 차량 시동 시 누구의 스마트폰이 연결되었는지 자동 식별하여 무단 반출 및 주 운전자를 판별합니다.
bleBeaconUuid 키보관함 식별 ID FG30-KEYBOX-01 본사 총무팀 키보관함(3m) 접근 이력 및 키홀더 QR 스티커와 1:1로 매칭되는 고유 코드입니다.
cumulativeGpsKm 초기 계기판 주행거리 14280.5 초기 등록 시점의 실제 계기판(Odometer) 수치입니다. 이후 반납 시마다 GPS 주행거리가 자동 합산됩니다.
parkingZone 기본 주차구역 Northpark Lot A #01 4400 Northpark Dr 본사 주차장 내 지정 주차면 번호입니다.

ITEM 03 주요 운전자(임직원) 사전 정보 수합 및 일괄 등록 가이드

개별 추가 & CSV 일괄 업로드 지원

관리자는 법인차량을 운행할 부서별 주요 운전자 5대 기본 정보를 사전에 취합하여 시스템에 등록합니다. 사전 등록된 운전자만 배차 신청 및 1초 QR 자율 반출이 가능하며, 미등록자나 배차 정지자(dispatchAllowed = N)는 자동 차단됩니다.

[인포그래픽 03] 주요 운전자 사전 명단 수합 → 관리자 콘솔 등록 → 실시간 권한 하트비트 감시 흐름도

💡 국·영문(KOR/ENG) 동시 표기를 위한 성명 입력 팁

운전자 성명을 박성훈 대리 (Dave Park)처럼 한글 성명 + 괄호 안 영문 성명 형태로 입력해 두면, 상단 메뉴에서 KOR 선택 시 한글로, ENG 선택 시 자동으로 Dave Park으로 변환되어 표시됩니다.

🚫 배차 허용 여부 (dispatchAllowed) 활용법

사전 명단에는 포함하되 면허 확인 전이거나 교육 미이수자인 경우 CSV의 dispatchAllowed 값을 N으로 입력하면, 명단에는 등록되지만 차량 배차 신청은 잠금(차단) 상태로 시작됩니다.

ITEM 05 운영 개시 후 주간 점검 — 계기판 실사 대조 및 유령 주행(Ghost Trip) 감사

주 1회 정기 점검 권장

임직원이 스마트폰 블루투스나 GPS를 고의로 끄고 차량을 몰래 운행하더라도, 관리자가 주 1회 실제 차량 계기판(Odometer) 숫자를 입력해 [실사 대조]를 누르면 누락된 주행거리(+5km 이상)와 용의자를 자동으로 적발합니다.

[인포그래픽 05] 주간 계기판 실사 대조(+5km 이상 오차)를 통한 유령 주행(Ghost Trip) 자동 색출 프로세스

ITEM 06 Microsoft 365(SharePoint · OneDrive Excel · Teams) 기반 기록 보관 및 월간 운영 절차

외부 DB(Supabase) 미연동 · 회사 M365 계정으로 운영

웹앱은 "오늘 누가 어떤 차를 타고 있는가"를 다루는 실시간 운영 장부이고, Microsoft 365는 "지난달 운행기록이 어디 있는가"를 답하는 보관 장부입니다. 관리자는 주 1회 관리자 콘솔의 CSV 내보내기로 운행일지·배차대장을 받아 SharePoint에 올리고, 월 1회 Excel 마스터에 병합합니다. 별도 서버 DB 계약이나 Azure 앱 등록은 필요 없습니다.

[인포그래픽 06] 웹앱 CSV 내보내기 → SharePoint 보관 → Excel 월간 통합 → Teams 알림·결재 4단계 M365 운영 파이프라인
주기 관리자 작업 Microsoft 365 산출물 위치
매일 퇴근 전 앱 상단 KPI(미반납 N대) 확인 후 Teams 채널에 캡처 게시 Teams #법인차량-배차
주 1회 (월요일) ① 계기판 실사 → [실사 대조] ② 관리자 콘솔 CSV 내보내기 ③ 업로드 SharePoint 차량운행기록/YYYY-MM/운행일지_YYYY-MM-DD.csv
월 1회 (1영업일) 주간 CSV를 Excel 마스터에 병합(붙여넣기 또는 Power Automate) → 부서별 피벗 → 회계팀 공유 OneDrive FleetGuard30_운행일지_마스터.xlsx
분기 1회 사고대장·유령주행 적발 건 검토, 배차 정지자 명단 갱신 (Teams 결재 스레드) Excel 사고대장 시트
연 1회 전년도 운행일지 PDF 변환 → 보존 레이블(7년) 적용 SharePoint YYYY/연간_운행기록부.pdf
M365 최초 1회 준비 (20분)
  1. SharePoint 사이트 FleetGuard30 · 라이브러리 차량운행기록 생성
  2. 권한: 차량관리자 편집 / 임직원 읽기 / 외부 공유 차단
  3. Teams 채널 #법인차량-배차 생성 (배포 URL 고정 메시지)
  4. OneDrive에 FleetGuard30_운행일지_마스터.xlsx (시트 4개) 생성
  5. (선택) Power Automate: CSV 도착 → Excel 행 추가 → Teams 게시
JSON DB 백업 · 보안 수칙
  • 서버의 data/fleet-db.json을 주 1회 복사 → SharePoint 백업/ 업로드 (OneDrive 동기화 폴더에 직접 두지 않음)
  • 관리자 PIN은 서버 환경변수 FLEET_ADMIN_PIN에만 보관, Teams 공개 채널·문서에 기록 금지
  • DB 초기화는 PIN 인증 후에만 가능 (미인증 API 호출은 401 거부)
  • 운행일지 CSV에는 휴대폰 번호를 포함하지 않음 (임직원 CSV는 마스터/ 폴더, 관리자만 접근)
  • 백업·운행기록 보존 기간 7년
